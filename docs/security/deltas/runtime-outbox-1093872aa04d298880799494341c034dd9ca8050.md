## 已完成（Runtime）

`packages/dsh-runtime` 的 SQLite 现在把 `bot_tasks` 与 `event_outbox` 放在同一事务。
Publisher 至少一次写入 `domain_events`（`INSERT OR IGNORE`）。

已落地并有测试：

- 同一 `aggregate_id` 按 `sequence` 投递；`UNIQUE (aggregate_id, sequence)`
- seq N 为 PENDING / CLAIMED / **DEAD** 时，seq N+1 不能发布
- `DEAD` 进 DLQ 后仍阻塞同 aggregate；必须人工审计 `replay` / `skip` / `terminate`
- 不同 aggregate 互不阻塞
- 失败增加 `attempts`，`available_at` 指数退避，超过上限进入 `DEAD`
- 重放只接收 `event_id`，从不可变 Outbox 记录读原 payload；`domain_events` 不出现第二条
- 已提交的 `CLAIMED` 使用 `locked_until` lease；过期后其他 Publisher 可接管
- Outbox 不可用时禁止直写 `domain_events`，也不退回「transition 后单独 emit」
